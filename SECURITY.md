# Security Policy

## Scope

This repository is an experimental security prototype. Detection rules, classifiers, PII screening, and canaries are heuristic and are not guarantees of protection. Do not use the project as the sole security control for production systems or submit real secrets, credentials, or personal data to it.

## Reporting a Vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting for this repository when available. If private reporting is unavailable, contact the maintainer privately through GitHub and include a concise description, affected component, and steps to reproduce without real credentials or sensitive data.

Reports are reviewed on a best-effort basis. There is no guaranteed response or remediation timeline.
